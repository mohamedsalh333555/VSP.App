# VSP Phase 8 — strict queued refund inputs, verified ledger and callback contradiction guards

**Date:** 17 November 2026. **Branch:** `uxlp-44-implementation`. All work is source-only and isolated CI; no real Paymob payment, refund or hosted schema mutation.

## Confirmed source issues and fixes

1. **Unsafe transaction-ID normalization and malformed cents** — the three cancellation refund queues previously stripped all non-digits from `item.paymob_transaction_id`, so a malformed value could be transformed into a different provider transaction identifier. Invalid/nonfinite or overprecise amounts also needed denial. [1efc8537](https://github.com/mohamedsalh333555/VSP.App/commit/1efc85372c8ce4a004e48f465fb4cea658ea40d1) adds a common positive safe integer / two-decimal EGP contract, exact provider ID, and tests across team tournament, old 1v1 and team league queues. [Deno+Flutter financial CI — SUCCESS](https://github.com/mohamedsalh333555/VSP.App/actions/runs/44119879534).
2. **Premature queue completion and ignored DB reconciliation errors** — after an accepted Paymob refund response, all three workers previously set `cancellation_refund_queue` / league counterpart `completed` **before** the order, registration and `transactions` updates; errors and zero-row updates were silently ignored, and a player could be notified incorrectly. [4756baca](https://github.com/mohamedsalh333555/VSP.App/commit/4756bacae36aaf515b4931bec53104fde6cbe1a4) requires exactly one verified updated row for each expected update, marks queue complete **last**, and routes failures to explicit manual ledger reconciliation without announcing customer success. [Deno+Flutter financial CI — SUCCESS](https://github.com/mohamedsalh333555/VSP.App/actions/runs/44120494385). These are still **multiple** PostgREST writes, not an atomic cross-table transaction; partial ledgers need manual repair and ideally a future DB RPC.
3. **Conflicting Paymob refund flags** — provider response `success:true` with explicit `is_refund:false` or string-typed boolean flags could previously be accepted as a refund. [1ff5b16c](https://github.com/mohamedsalh333555/VSP.App/commit/1ff5b16cb6613748daa14c91cab6b09f3141411b) rejects contradictions and nonboolean flags for safe manual reconciliation and clears an obsolete gateway dispatch warning on **successfully completed** queue rows. [Latest Deno+Flutter finance CI — SUCCESS](https://github.com/mohamedsalh333555/VSP.App/actions/runs/44121083855).
