## 2. فحص قارئ الشاشة (`uiautomator` / ARIA Accessibility)

1. **`VSP.App` (`Pixel_9` XML dumps):** رُصدت عناصر حرجة بوسم **`NAF="true"` و`content-desc=""`**: زر المتابعة الأخضر في الترحيب (`01_`), `VSPBackButton` (`02_`..`42_`), وأيقونة العين في كلمة المرور (`10_`).
2. **`vsp_website`:** زر تبديل اللغة يفتقد `aria-label` صريح؛ القفز العناويني `h2 -> h4` يكسر شجرة قارئات الشاشة.
3. **`vsp-admin-panel`:** خاصية `select-none` على حاوية `LoginPage` تمنع المشرف من تحديد ونسخ رسالة رفض الصلاحية عند التواصل مع الدعم.
