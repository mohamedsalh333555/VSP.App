## قواعد العداد

1. **OPEN / BLOCKED:** لم يستوفِ شرط القبول، ولا ينقص من المتبقي.
2. **CODE_DONE / NEEDS_ACCEPTANCE:** الكود أو الاختبار أنجز جزءًا محددًا؛ لا يتغير العداد حتى يكتمل معيار القبول المتفق عليه.
3. **ACCEPTED:** معرف مهمة أصلي فريد أُغلق مع دليل تشغيل ونطاق واضح، يُحتسب مرة واحدة فقط.
4. حاليًا `المتبقي = 640 − المقبول`؛ الأصل 633 محفوظ والمجموعة 86 أضافت 7 فقط، ولا نساوي الـCommits أو الاختبارات بعدد المهام.
5. لكل دفعة جديدة يلزم تحديث **القائمة التفصيلية، الخطة، دفتر التسليم وهذا العداد** ثم تشغيل `scripts/verify_task_accounting.py`.
6. المجموعة الملغاة **56** لا تعود، ومجموعة **84** تظل 12 مهمة قائمة مستقلة دون زيادة مصطنعة في الإجمالي.
