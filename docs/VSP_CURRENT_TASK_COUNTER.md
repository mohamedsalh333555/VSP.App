## قاعدة الحساب من الآن

1. **OPEN**: مهمة موجودة من الـ630 ولم تستوفِ شرط القبول.
2. **CODE_DONE / NEEDS_ACCEPTANCE**: تم تغيير الكود أو اجتاز اختبارات
   محددة، لكن شروط القبول المتبقية لم تنجح؛ لا يتحرك العداد الرسمي.
3. **ACCEPTED**: تحقق شرط قبول المهمة المحدد، مع دليل SHA / اختبار / نطاق
   التشغيل؛ يُحوّل سطر المهمة الفريد إلى `[x]` ويُخصم **واحد فقط** من
   المتبقي.
4. **BLOCKED**: توثيق العائق والاختبار المفقود، ولا يُحسب مكتملًا.
5. التعديل الصحيح في **كل دفعة** هو:
   `مكتمل جديد = مكتمل سابق + عدد IDs المقبولة الجديدة`،
   `متبقي جديد = 630 - مكتمل جديد`.
   لا تُحسب الملفات أو الاختبارات أو الـCommits كمهام.
6. لا يُنشأ معرف مكرر أو يُعاد إدخال المجموعة الملغاة 56، ولا تُدمج المهام
   الجديدة في الـ630 دون إعلان تغيير النطاق.
